Types of Middleware:
- Generic Middleware
- Error Handler
- Route Handler

Presentation Tier -- what users see and interact with.
Application Tier -- Where logic lives. The application tier receives HTTP requests, routes them to the appropriate handlers, processes user input, interacts with the database, etc.
Data Tier -- where information is stored, retrieved, and managed.
